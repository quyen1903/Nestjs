## Owner decisions still required

- The external API prefix and live envelope have been selected from existing
  frontend compatibility. Any replacement contract requires an owner-approved
  versioning plan.
- Physical conversion of legacy money/timestamp columns is outside parity and
  requires rounding, backfill, export, and rollback approval.
- Realtime remains disabled until a Socket.IO compatibility or client-version
  decision is approved.
